# Outil_CrunchAudit_Tool
Ce répertoire constitue la zone de dépôt du logiciel CrunchAudit_tool. Il contient l'exécutable du programme, sa documentation utilisateur, les fichiers sources Python d'origine (dont main.py et les modules de routines associés), ainsi que le fichier .dat nécessaire au processus de compilation permettant de générer l'exécutable.
